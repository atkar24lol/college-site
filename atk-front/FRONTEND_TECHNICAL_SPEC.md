# Техническое задание: воссоздание фронтенда сайта АТК (Агротехнический колледж)

Документ описывает стек, архитектуру, маршруты, интеграцию с API и контент так, чтобы по нему можно было заново реализовать клиентскую часть проекта.

---

## 1. Назначение и общее описание

**Продукт:** многостраничный публичный сайт колледжа с тремя языками интерфейса (RU / EN / KY), шапкой и подвалом на всех страницах, блоками с данными из REST API Django (бэкенд `college-back`).

**Ключевые возможности:**
- Локализованный контент UI через JSON-словари (не через API).
- Динамические списки и детальные страницы (новости, преподаватели, программы, специальности и т.д.) с бэкенда.
- Поиск по сайту (глобальный поиск API).
- Интерактивная карта (Leaflet + OpenStreetMap) на главной.
- Адаптивная вёрстка (Tailwind, кастомные брейкпоинты).

## 4. Маршрутизация и i18n

### 4.1. Языки

- **Поддерживаемые локали в URL:** `ru`, `en`, `ky` (в коде словари импортируются как `ky`, не `kg`).
- **Дефолтный вход:** редирект с `/` на `/ru` через `next.config.mjs` → `rewrites`.

### 4.2. Паттерн страниц

- Каждая страница живёт в `src/app/[lang]/...`.
- **Серверный** `page.js` (по возможности) вызывает `getDictionary(lang)` и передаёт `dict` в клиентский компонент.
- Клиентские компоненты помечены `"use client"`, используют `useParams()` для `lang` и динамических сегментов.

### 4.3. Перечень маршрутов (реализованные в проекте)

| URL-паттерн | Назначение |
|-------------|------------|
| `/` → `/ru` | Редирект на русскую главную |
| `/[lang]` | Главная: новости, инфоблоки, форма, карта |
| `/[lang]/news` | Список новостей с пагинацией (MUI) |
| `/[lang]/news/[newsId]` | Детальная новость |
| `/[lang]/contacts` | Контакты (список из API) |
| `/[lang]/additional-education` | Сертификаты (галерея изображений из API) |
| `/[lang]/awards` | Награды |
| `/[lang]/education-activity` | Образовательная деятельность (текст из словаря + разметка markdown-подобного текста) |
| `/[lang]/gallary` | Мультимедиа / галерея |
| `/[lang]/entrants` | Абитуриентам: даты приёма, специальности, FAQ |
| `/[lang]/electron-library` | Электронная библиотека (образцы файлов) |
| `/[lang]/teachers` | Преподавателям (расписание и т.п.) |
| `/[lang]/teachers/[teacherId]` | Карточка преподавателя |
| `/[lang]/about-teachers` | Список преподавателей |
| `/[lang]/international-cooperation` | Список программ с пагинацией |
| `/[lang]/international-cooperation/[programm]` | Детальная программа |
| `/[lang]/specialities` | Оглавление специальностей (если есть) |
| `/[lang]/specialities/[specialityId]` | Страница специальности (агрономия, ветеринария и т.д.) |
| `/[lang]/search/[value]` | Результаты глобального поиска |
| `/[lang]/site-map` | Карта сайта |

**Примечание:** в шапке/баннере может фигурировать путь `/${lang}/feedback`, отдельного роута `feedback` в `app` может не быть — при воссоздании уточнить и либо добавить страницу, либо убрать ссылку.

## 5. Глобальная оболочка (layout)

- **`<html lang='ru'>`** — в текущем проекте фиксирован `ru`; при улучшении можно привязать к `params.lang`.
- Подключение **Montserrat** (несколько начертаний), классы шрифтов на `<html>`.
- **`<body>`:** сверху **Header**, контент страницы `children`, снизу **Footer**.
- Favicon: `/favicon.ico`.

## 6. Локализация UI (словари)

- Файлы: `src/dictionaries/ru.json`, `en.json`, `ky.json`.
- Загрузка: динамический `import()` в `dictionaries.js` по ключу локали.
- Структура JSON — иерархическая: `header`, `footer`, `mainPage`, `blogAndNews`, `contacts`, `entrants`, `siteMap`, тексты для форм, кнопок, превью в шапке и т.д.
- **Контент с бэкенда** для мультиязычности часто приходит полями вида `title_ru`, `title_en`, `title_ky`, `description_*`, `role_*` — в компонентах используется шаблон `` `title_${lang}` `` (и аналоги).

## 7. Интеграция с API

### 7.1. Клиент HTTP

- Файл `src/requester.js`: один экземпляр **Axios** с `baseURL`.
- **Текущий пример baseURL:** `http://localhost:8000//ru/api/v1/` (в проде заменить на переменную окружения `NEXT_PUBLIC_API_URL` и убрать лишний слэш при необходимости).

### 7.2. Формат ответов

- Списочные эндпоинты DRF с пагинацией возвращают объект вида `{ count, next, previous, results: [...] }`.
- На фронте везде, где нужен полный список, передавать **`page_size`** (бэкенд должен поддерживать query-параметр `page_size`, см. `PageSizePagination` в `college-back`), например `page_size: 100` для контактов и сертификатов.

### 7.3. Таблица эндпоинтов (относительно baseURL)

| Относительный путь | Где используется |
|--------------------|------------------|
| `news/news/?page=1&ordering=-date&page_size=5` | Главная — последние новости |
| `news/news?page=N` | Страница всех новостей |
| `news/news/{id}/` | Детальная новость |
| `abouts/contacts/?page=1&page_size=100` | Контакты |
| `abouts/sertificates/?page=1&page_size=100` | Сертификаты на странице доп. образования |
| `abouts/awards/` | Награды |
| `abouts/lecturers/` | Список преподавателей |
| `abouts/lecturers/{id}/` | Карточка преподавателя |
| `abouts/images-of-multimedia/` | Галерея |
| `abouts/faq` | FAQ абитуриентам |
| `abouts/sample/` | Электронная библиотека |
| `abouts/global-search/?q={value}` | Поиск |
| `education/courses-programms` | Курсы/программы (доп. образование и др.) |
| `education/courses-programms?page=N` | Международное сотрудничество |
| `education/courses-programms/{id}/` | Деталь программы |
| `education/admission-dates` | Даты приёма |
| `education/schedule?page=N` | Расписание (преподавателям) |

Медиа-URL с бэкенда могут быть относительными — при необходимости дополнять базовым URL медиа-сервера.

## 8. Ключевые особенности реализации по страницам

### 8.1. Главная (`/[lang]`)

- Клиентский компонент: загрузка новостей через API, состояние `news`.
- Блоки: **MainNewsBlock**, **MainInfoBlock**, **MainFormBlock**, **Map**.
- **Карта:** компонент на Leaflet; подключать через `next/dynamic` с **`ssr: false`**, чтобы не было `window is not defined`.
- Обертка карты: **`id="map"`** для прокрутки с шапки (иконка геоточки): `scrollIntoView` или переход `/${lang}#map` + `useEffect` на главной при `location.hash === '#map'`.

### 8.2. Новости

- Список: пагинация MUI, `pageSize` в состоянии (например 3 на страницу — как в бэкенде по умолчанию).
- Карточки ведут на `/[lang]/news/[id]`.
- Детальная: запрос по `newsId`, разбиение описания по `\n` на параграфы.

### 8.3. Контакты

- Нормализация ответа: массив или `results`.
- Отображение полей с учётом опечаток в ключах в шаблоне (`role_${lang} ` с пробелом как fallback).

### 8.4. Образовательная деятельность

- Контент из словаря; парсинг текста: заголовки `#`, списки `* `/`- `, жирный `**text**` через `dangerouslySetInnerHTML` в пунктах списка.

### 8.5. Шапка (Header)

- Условная логика по **`usePathname()`**: разные превью-картинки, заголовки и описания для каждого раздела.
- Переключение языка: замена первого сегмента пути на выбранный `lang`.
- Поиск: переход на `/[lang]/search/[value]`.
- Верхняя синяя полоса: телефон → контакты, геоточка → скролл к карте на главной, внешняя ссылка на портал и т.д.

### 8.6. Подвал (Footer)

- Три колонки ссылок + соцсети; словари для подписей; логотип ведёт на главную `/${lang}/`.

## 9. Стили и адаптив

- **Tailwind:** utility-классы в JSX; часть страниц имеет локальные `styles.css`.
- **Брейкпоинты** (кастом в `tailwind.config.js`):
  - `sm`: 0–600px  
  - `md`: 600–1024px  
  - `lg`: 1024–1200px  
  - `xl`: 1200–1500px  
  - `xxl`: 1500–1920px  

Часто используются префиксы `sm:`, `md:`, `lg:`, `xl:` для отступов, размеров шрифтов, скрытия элементов (`md:hidden` и т.п.).

- Фирменный синий в UI: в т.ч. `#0084DA`, `#0079C1`, `#0072BC`.

## 11. Переменные окружения (рекомендация при воссоздании)

Создать `.env.local`:

```env
NEXT_PUBLIC_API_BASE=http://localhost:8000/ru/api/v1/
```

В `requester.js` использовать `process.env.NEXT_PUBLIC_API_BASE` вместо захардкоженного URL.

```bash
cd atk-front
```

## 13. Критерии приёмки (минимум)

1. Все маршруты из раздела 4.3 открываются без ошибок в консоли (при работающем API).
2. Переключение `ru` / `en` / `ky` сохраняет путь после первого сегмента.
3. Списки с пагинацией на бэкенде при необходимости запрашивают `page_size`, чтобы не обрезать данные до 3 элементов там, где нужен полный список.
4. Главная: карта без SSR-ошибки; клик по геоточке в шапке на главной прокручивает к карте.
5. Сборка `npm run build` проходит успешно.

---

## 14. Известные ограничения текущей реализации

- В `requester.js` задвоенный слэш в URL (`//ru`) — лучше нормализовать.
- В `i18n.config.js` есть некорректная строка с `Locale` — для Next не критично, если локали задаются только в `[lang]` и словарях.
- Часть контента на главной/доп. образовании может быть закомментирована (курсы, преимущества) — при полном воссоздании сверить с макетом.
